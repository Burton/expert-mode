# Expert Mode

*Expert Mode* is a novel about how to get things done in government, in spite of all the obstacles.

New chapters are published at [concrete.matthewburton.org/expert-mode](https://concrete.matthewburton.org/expert-mode). To receive every chapter by email as it is released, [subscribe](https://concrete.matthewburton.org/#/portal/signup).

This repository contains the text of every published chapter. When I change a chapter after publication, the change is recorded in this repository's commit history.
